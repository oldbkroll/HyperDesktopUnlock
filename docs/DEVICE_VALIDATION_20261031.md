# 2026-10-31 针对性实机验证结果

构建：Unlock 1.12.8-extend-cn.7 (245)，Extend 0.0.27-zh-cn.2 (29)。设备：小米17 Pro Max popsicle，HyperOS OS4.0.5.0.XPBCNXM / Android17。用户操作并反馈，助手抓取日志；未用uiautomator干扰无障碍。

## 本轮通过

| 场景 | 结果及证据边界 |
| --- | --- |
| 第六版手动移除外屏系统桌面任务 | 用户报告手势恢复，后续DPI往返和缩放正常；手机桌面PID不变，外屏应用保持运行 |
| 第七版自动阻止系统副屏桌面启动 | 模块日志记录两次skipped stock external home on display2；活动表没有SecondaryDisplayLauncher；没有手动移除任务 |
| 独立外屏DPI 150→200→150 | 用户按步骤反馈画面正常、手势正常；最终外屏150DPI，内屏480DPI |
| 独立外屏缩放100%→125%→100% | 用户按步骤反馈正常；最终外屏2560×1440、rotation0，内屏1200×2608、rotation0 |

两项“强制桌面能力”诊断设置未写入，实际使用默认关闭；总开关开启，mirror_built_in_display=0。DPI/缩放回归后SecondaryDisplayLauncher仍不存在，桌面进程保持运行。结果支持通过避开副屏系统桌面来规避该固件的内屏手势问题；没有对厂商原生代码缺陷的具体实现作完整证明。

## 既有功能与未覆盖项

总开关关闭恢复镜像和关闭后重连恢复手势，在第二版/此前对照已观察通过；第七版没有重新完整遍历所有开关组合。系统弹窗显式镜像补写分支、既有副屏home根任务的自动清理API分支未单独触发验证，保持SKIPPED；本版已证明的是自动防启动路径。关闭模块不自动重建已阻止的桌面任务，需要重新连接走原生路径。

原先剩余完整矩阵继续SKIPPED：触控板/键鼠/IME完整路由，真实关屏及恢复、拔线恢复、多外屏、托管虚拟显示、长时稳定性/性能、DP与HDMI分别验证、高刷及实际FPS。设置页topology-fix MISSING、固定竖屏应用letterbox、高刷设置后实际60Hz等旧边界没有被本轮修复或重新验证。
